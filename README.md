# Operadores IA Studio v2

App web para crear imágenes y videos con la API de Higgsfield. El proyecto está en [`operadores-studio-v2/`](operadores-studio-v2/); ahí están las instrucciones de instalación y uso.

Para correrlo localmente, instalá Node.js 22.15 o posterior y pnpm, y luego ejecutá:

```bash
cd operadores-studio-v2
pnpm install
pnpm setup
pnpm dev
```

Abrí la dirección local que indique la terminal. Cada persona conecta su propia clave de Higgsfield desde la app. No hay claves de API incluidas en el repositorio.
